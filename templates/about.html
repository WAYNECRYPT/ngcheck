🛡️ About NGcheck

NGcheck is a phishing detection tool built to help protect Nigerian internet users -- especially bank customers -- from fake websites designed to steal their login details, card information, and personal data.

Phishing attacks targeting Nigerian banks and government platforms (like JAMB) are a growing problem. Attackers often register domains that look almost identical to real ones -- swapping a letter, adding a hyphen, or using a different extension -- hoping victims won't notice the difference. NGcheck exists to catch exactly that.

How It Works

Paste any website URL into the scanner on the home page. NGcheck runs five independent checks and combines the results into one overall risk score:

  • HTTPS Check -- confirms the site uses a secure connection
  • .ng Domain Verification -- checks whether the domain is genuinely registered with NIRA (Nigeria's domain registry)
  • Look-alike Domain Detection -- compares the domain against known Nigerian bank domains to catch typosquatting (e.g. "gtbnak.com" instead of "gtbank.com")
  • SSL Certificate Validation -- checks whether the site's security certificate is valid and how recently it was issued
  • Phishing Blacklist Lookup -- checks the URL against Google's Safe Browsing database of known threats

A Note on Limitations

NGcheck is an automated tool, not a guarantee. Some checks depend on live internet access and third-party services, and may occasionally return "unable to verify" instead of a clear result -- this is treated as neutral, not as a red flag, so a temporary network issue never makes a safe site look dangerous. Always use your own judgment alongside these results, especially before entering sensitive information on any website.

Project Background

NGcheck was built as a final-year Computer Science project at Nasarawa State University, Keffi, exploring how AI and web tools can be applied to real-world cybersecurity problems in the Nigerian context.
